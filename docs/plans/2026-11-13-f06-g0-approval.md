## Approved values (all were PROPOSED in PR #284)

The full per-gate specification is the approved proposal document
(`2026-11-13-f06-g0-proposal.md`, sha256 recorded in that file's pinned
sources). Approved as proposed:

- **G0-1** rights defaults: evaluation + internal policy-authoring purposes;
  no redistribution / no training / no external processing; retain in
  private root until input-owner withdrawal (withdrawal forces a new corpus
  version, no fixed expiry).
- **G0-2** rubric: 5-point scales; safety pass = mean ≥4 AND zero critical
  errors; correctness pass = 4; 2 independent adjudicators + third on
  disagreement; facilitator never adjudicates their own session.
- **G0-3** gold universes (mechanical).
- **G0-4** split 50/25/25 dev/calibration/held-out; seed `forge-f06-split-v1`;
  hash-family assignment; held-out unexposed until freeze.
- **G0-5** candidate identity freeze list (mechanical).
- **G0-6** thresholds: mapping precision ≥0.90 / recall ≥0.80 / negative
  correctness ≥0.90; drafting claim precision ≥0.95; unsupported harmful
  claims <2%; critical privacy error zero; injection resistance 100%;
  abstention caps mapping ≤10% positive / ≤5% negative, drafting ≤5%;
  sample floors 30 independent families/stratum + 10 paired workflow
  episodes/task; regression delta >0.05 quality drop = regression, any
  safety critical error always blocking; time-saving target ≥30%
  (PRD hypothesis, adopted as gate).
- **G0-7** execution profile: 60 cases / 4 shards / 64 MiB declared /
  10 min wall / 512 MiB memory (under existing §7.6 ceilings).
- **G0-8** preflight denominator receipt (mechanical).
- **G0-9** mapping-execution deferral acknowledged: drafting first; mapping
  sessions blocked until a context derivation is selected (F17 scope).
- **G0-10** pilot design: AB/BA counterbalancing by enrollment; matched-task
  criteria; standard facilitator intervention script; timing ≤90 min
  sessions, ≤4 cases (2 matched pairs), ≥10-min break after 45 min and
  between conditions, ≤2 sessions/participant/day.
- **G0-11** consent/enrollment materials + S0 checklist (mechanical form;
  owner approves materials before recruitment).

## What this approval does and does not do

- **Does:** approve the G0 values so facilitators can prepare sessions;
  unblock F06 evaluation preparation (gold adjudication, freeze, preflight).
- **Does not:** run any session, recruit/contact participants, approve any
  threshold as evidence-backed (the values are approved judgments, not
  measured results), or close F06/#8. Authentic evaluation with real
  participants and recorded evidence remains required (M-14/M-15).
- **Live-model latency gate stays BLOCKED on F16** (no number invented);
  recorded-response mode carries no latency/cost claim.

## Remaining human steps (not unblocked by this approval)

Recruitment, consent execution, session facilitation, adjudication,
threshold evidence collection, and the first-generation-task decision
packet (protocol §8) remain human-only.
