## Exercised behavior

An authentic pre-adapter run passed the three real native-capture controls and
failed three positive command controls because `outbound` was absent. After the
Root CLI integration, those controls passed. An additional actual admitted-capture
test failed against recursive derived Debug; the count-only manual implementation
passes and internal raw-capture Debug derives are removed. Ordinary formatting
can no longer print held originals or private paths through this prepared object.

The focused green run passed seven native/CLI tests, and the unit run passed 14
parser, projection, schema and actual selection-file generation tests. The complete
POA&M foundation run passed 72 tests. These are historical source cohorts, preserved
in the receipt and never added to the final full-run denominator.

The controls exercise all three explicit intents, real finding/risk selections,
exact 64/65-owner boundaries, complete native equality, literal raw-byte hashes,
stable operation identities versus mutable payload/generations, seven held-source
drifts, actual selection replacement, eight-input output preflight, a distinct
output root with a matching basename, default and explicit intervals, overdue and
leap-date success, malformed/stale input refusal, and source non-mutation.
Case-insensitive filesystems may reject an existing destination before reaching
the conservative alias comparison; the tests do not claim every alias branch ran.

Linux/macOS publisher controls are conditional on the current platform. Portable
stdout and unsupported-platform source branches are retained. A local macOS test
run does not establish execution of the Windows publication-refusal branch.
Synthetic fixtures and static reviews provide no representative-plan, actor,
human, independent OSCAL consumer or remote adapter acceptance.

Strict all-target/all-feature Clippy passed after two preserved failed attempts:
two module-test and three integration-test lint diagnostics were fixed in test
helpers/bodies only. Formatting passed. Original native admission, matching,
schema, source recheck and projection bodies were preserved across those fixes.
The existing 130,192-byte foundation source remains an exact prefix of the final
file. Of 288 existing named functions across the eight-file cohort, 287 bodies
remain byte-exact; the CLI dispatcher adds the new arm. The shared native schema
validator changes visibility/documentation while preserving its body.
