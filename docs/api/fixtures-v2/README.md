# API v2 fixture family

These synthetic fixtures validate against the independently versioned [API v2 document](../forge-workspace-v2.openapi.yaml). Session fields require major2 and exact2.3.0. Index1 fixtures retain their own closed interpretation; index2 and cross-version controls are exercised by `api_contract_validation` and real-process `workspace_cli_test` controls. A schema-valid fixture does not prove native admission, freshness or human acceptance.

The project-bundle-effects cohort contains strict synthetic schema fixtures for the three API2.2 metadata effect routes and complete wrapped index replacement. Historical80 manifest entries retain their meaning; only the two Session minor-version literals are adapted. Valid means wire-shape only. Duplicate/BOM rejection, normalized hashes, pin order, actual files/domain admission, current-index downgrade, capacity/deadline/idempotency/cleanup and committed exact-byte family checks require separate producer/runtime controls. See the author packet runtime-control-matrix.json; no native result is implied.

The project-source-bundle cohort adds 22 synthetic fixtures for API2.3's six
source export/restore operations and complete wrapped source preview. The
independently packaged source bundle3 schema admits the closed
`index-and-source-hex` wire profile. API2 now declares 57 operations; API1 remains
1.2.0/39. Older operation DTOs and metadata fixture meanings remain intact;
Session negotiation moves to 2.3.0.

Wire validity does not establish exact hashes, decoded-byte closure, current
target versions, complete path/generation/quota admission, durable acceptance,
native ownership, index-last publication, conditional rollback or cleanup.
Native producer/runtime controls must establish those separately. A known
restore operation ID is a lookup key, not a reusable confirmation receipt.
See [the source workflow](../../workspace-source-bundles.md) for explicit review,
sensitivity, finite profile bounds and recovery. Dated verification records
retain their original source/contract scope.
