**Branch**: `021-prd-golden-file-tests` | **Date**: 2026-02-14

## Prerequisites

- Rust stable 1.93.0+ with `cargo`
- FORGE codebase with WI-1 through WI-20 complete (pipeline functional)
- `cargo-insta` CLI installed: `cargo install cargo-insta`

## Run Golden-File Tests

```bash
# Run all golden-file tests
cargo test golden

# Run a specific fixture test
cargo test golden_small_catalog
cargo test golden_medium_component

# Run with verbose output to see accuracy reports
cargo test golden -- --nocapture
```

## Update Golden Files After Intentional Changes

When a pipeline change intentionally alters output:

```bash
# Run tests to generate new snapshots (will show pending changes)
cargo insta test

# Review each pending snapshot interactively
cargo insta review

# Accept all pending snapshots (use with caution)
cargo insta accept
```

For expected JSON files (schema validation artifacts):

```bash
# Set env var to overwrite expected JSON files with actual output
UPDATE_GOLDEN_FILES=1 cargo test golden
```

## Add a New Fixture

1. Create a directory under `tests/fixtures/golden/<name>/`
2. Write `input.md` with YAML frontmatter and policy content
3. Run the pipeline to generate initial output:
   ```bash
   cargo run -- convert tests/fixtures/golden/<name>/input.md --strategy catalog --output /tmp/catalog.json
   cargo run -- convert tests/fixtures/golden/<name>/input.md --strategy component --output /tmp/component.json
   ```
4. Hand-verify the output against the input document
5. Validate against OSCAL schema:
   ```bash
   cargo run -- validate /tmp/catalog.json
   cargo run -- validate /tmp/component.json
   ```
6. Copy validated outputs to fixture directory:
   ```bash
   cp /tmp/catalog.json tests/fixtures/golden/<name>/expected-catalog.json
   cp /tmp/component.json tests/fixtures/golden/<name>/expected-component-definition.json
   ```
7. Add test functions to `tests/golden_file_tests.rs`
8. Run `cargo insta test` to generate initial snapshots
9. Run `cargo insta review` to accept the snapshots

## Fixture Design Guidelines

| Tier | Sections | Requirements | Features Exercised |
|------|----------|-------------|-------------------|
| small | 1 | 3-5 | Basic structure, Catalog/Component, metadata, JSON, UUIDs |
| medium | 3-5 | 10-15 | Multi-section hierarchy, citations, back matter, traceability |
| complex | 5+ | 20+ | Atomization, compound statements, cross-refs, all M-1 through M-11 |

    └── golden_file_tests__*.snap

## Key Commands

| Command | Purpose |
|---------|---------|
| `cargo test golden` | Run all golden-file tests |
| `cargo test golden -- --nocapture` | Run with accuracy report output |
| `cargo insta test` | Run tests and detect pending snapshots |
| `cargo insta review` | Interactive review of pending snapshots |
| `cargo clippy -- -D warnings` | Lint check (must pass) |
| `cargo fmt --check` | Format check (must pass) |
