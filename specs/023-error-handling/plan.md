# Implementation Plan: Error Handling & Robustness (WI-23)

**Branch**: `023-error-handling` | **Date**: 2026-02-13 | **Spec**: [023-prd-error-handling](../../docs/PRD/023-prd-error-handling.md)
**Input**: PRD 023, AR 023, SEC 023

## Summary

Systematic error handling hardening across the FORGE pipeline. Expand the existing `ForgeError` enum with dedicated variants for file-not-found, permission-denied, empty-input, and no-structure-detected conditions. Add `anyhow` for `.context()` propagation in `main.rs`. Implement differentiated exit codes (1=input/IO, 2=parse/structure, 3=validation). Audit and document all `.unwrap()`/`.expect()` calls in production code. Add binary content detection to the ingestion stage. Create an adversarial input test suite. Wire `--verbose`/`--quiet` flags to tracing subscriber initialization.
