# Implementation Plan: Validation Error Reporting (WI-20)

**Branch**: `020-prd-validation-error-reporting` | **Date**: 2026-02-14 | **Spec**: [PRD](../../docs/PRD/020-prd-validation-error-reporting.md)
**Input**: [PRD](../../docs/PRD/020-prd-validation-error-reporting.md), [AR](../../docs/AR/020-ar-validation-error-reporting.md), [SEC](../../docs/SEC/020-sec-validation-error-reporting.md)

## Summary

Enhance FORGE's validation error reporting to make validation errors actionable. Transform raw `jsonschema` crate errors into user-friendly messages with JSON Path notation, expected/actual values, and error categorization (schema vs. semantic). Implement semantic validation to detect orphaned back-matter links and missing control-id references. Integrate enhanced error reporting into both `forge validate` and `forge convert` auto-validation. Support `--format json` for machine-parseable error output.
