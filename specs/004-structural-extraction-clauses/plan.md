# Implementation Plan: Structural Extraction — Clauses & Tables

**Branch**: `004-structural-extraction-clauses` | **Date**: 2026-02-11 | **Spec**: `specs/004-structural-extraction-clauses/spec.md`
**Input**: Feature specification from `/specs/004-structural-extraction-clauses/spec.md`

## Summary

Extract ordered list items, unordered list items, GFM tables, and standalone paragraphs from Markdown content using pulldown-cmark's event-based parser with a depth counter for nesting. Produces typed `ExtractedContent` with `ExtractedListItem`, `ExtractedTable`, and `ExtractedParagraph` structs, each carrying source line numbers. Follows AR-004 Option 1 (Event-Based Pattern Matching with Depth Counter) and SEC-004 security requirements (SEC-1 through SEC-7).

## Design

### Architecture (AR-004 Option 1: Event-Based Pattern Matching with Depth Counter)

Event-based O(n) iteration over pulldown-cmark events with `Options::ENABLE_TABLES` enabled, followed by O(n log n) sorting of list items to restore document order. Three concurrent state machines operate within the same event loop:

1. **List extractor**: Depth counter via `Vec<ListType>` stack. `Start(List)` pushes, `End(List)` pops. `Start(Item)` begins accumulation, `End(Item)` finalizes. `nesting_depth = stack.len().saturating_sub(1).min(255) as u8` *(SEC-4 saturation)*. Items are sorted by source line after extraction because nested items complete (and are pushed) before their parents, violating document order.

2. **Table extractor**: State machine tracking `in_header` vs `in_data_row`. `Start(Table)` initializes, `Start(TableHead)`/`Start(TableRow)` toggle mode, `Start(TableCell)` begins cell accumulation, `End(Table)` finalizes. Empty cells produce empty strings *(SEC-2)*.

3. **Paragraph extractor**: Captures standalone `Paragraph` blocks that are not inside list items or table cells.

**Inline formatting** is stripped naturally by consuming only `Text`, `Code`, and `SoftBreak` events within accumulation contexts *(SEC-3, R-5)*.

**Line number mapping** reuses `build_line_starts()` and `offset_to_line()` from `parse/mod.rs` (promoted to `pub(crate)`) *(R-2)*.

**Excluded content within list items**: `CodeBlock` and `BlockQuote` blocks are excluded via an `exclude_depth` counter *(EC-8, R-4)*.

### AR Implementation Guardrails (MUST follow)

- **DO NOT** extract headings (WI-3 scope)
- **DO NOT** classify list items as requirements vs informational (downstream logic)
- **DO NOT** atomize compound statements (WI-6 scope)
- **DO NOT** detect normative vs advisory language (WI-33 scope)
- **DO NOT** associate items with sections (WI-5 scope)
- **MUST** use `Options::ENABLE_TABLES` *(SEC-7)*
- **MUST** use depth counter, not indentation parsing *(SEC-4, SEC-6)*
- **MUST** preserve source line numbers on every element *(M-4)*
- **MUST** strip inline formatting to plain text *(SEC-3)*
- **MUST** use `u8` for `nesting_depth` with saturation *(SEC-4)*

    pub source_line: usize,    // 1-based (M-4)

    pub tables: Vec<ExtractedTable>,
    pub paragraphs: Vec<ExtractedParagraph>,

### Algorithm Pseudocode (AR-004)

```text
fn extract_clauses(content: &str) -> Result<ExtractedContent, ForgeError>:
    let options = Options::ENABLE_TABLES
    let parser = Parser::new_ext(content, options)
    let line_starts = build_line_starts(content)

    let mut list_type_stack: Vec<ListType> = []
    let mut current_item_text: Option<String> = None
    let mut current_item_line: usize = 0
    let mut exclude_depth: usize = 0        // for CodeBlock/BlockQuote exclusion

    let mut in_table: bool = false
    let mut in_header: bool = false
    let mut current_row: Vec<String> = []
    let mut current_cell: Option<String> = None
    let mut current_table: Option<ExtractedTable> = None

    let mut in_standalone_paragraph: bool = false
    let mut current_para_text: Option<String> = None
    let mut current_para_line: usize = 0

    let mut result = ExtractedContent { list_items: [], tables: [], paragraphs: [] }

    for (event, range) in parser.into_offset_iter():
        match event:
            Start(List(Some(_))) => list_type_stack.push(Ordered)
            Start(List(None))    => list_type_stack.push(Unordered)
            End(List)            => list_type_stack.pop()

            Start(Item) =>
                current_item_text = Some("")
                current_item_line = offset_to_line(range.start, &line_starts)
                exclude_depth = 0
            End(Item) =>
                if let Some(text) = current_item_text.take():
                    if !text.trim().is_empty():
                        let depth = list_type_stack.len().saturating_sub(1).min(255) as u8
                        result.list_items.push(ExtractedListItem { ... })

            Start(CodeBlock|BlockQuote) if current_item_text.is_some() =>
                exclude_depth += 1
            End(CodeBlock|BlockQuote) if current_item_text.is_some() =>
                exclude_depth = exclude_depth.saturating_sub(1)

            Start(Table(_)) =>
                in_table = true
                current_table = Some(ExtractedTable { headers: [], rows: [], source_line: offset_to_line(...) })
            Start(TableHead) => in_header = true
            Start(TableRow)  => current_row = []
            Start(TableCell) => current_cell = Some("")
            End(TableCell)   => current_row.push(current_cell.take().unwrap_or_default())
            End(TableHead)   =>
                current_table.headers = current_row.drain(..).collect()
                in_header = false
            End(TableRow)    =>
                current_table.rows.push(current_row.drain(..).collect())
            End(Table)       =>
                if let Some(table) = current_table.take():
                    result.tables.push(table)
                in_table = false

            Start(Paragraph) if list_type_stack.is_empty() && !in_table =>
                in_standalone_paragraph = true
                current_para_text = Some("")
                current_para_line = offset_to_line(range.start, &line_starts)
            End(Paragraph) if in_standalone_paragraph =>
                if let Some(text) = current_para_text.take():
                    if !text.trim().is_empty():
                        result.paragraphs.push(ExtractedParagraph { ... })
                in_standalone_paragraph = false

            Text(t) | Code(t) =>
                // Accumulate into active context (item, cell, or paragraph)
                if current_item_text.is_some() && exclude_depth == 0:
                    current_item_text += &t
                elif current_cell.is_some():
                    current_cell += &t
                elif in_standalone_paragraph:
                    current_para_text += &t

            SoftBreak =>
                // Treat as space in all contexts
                accumulate " " into active context

    Ok(result)
```
