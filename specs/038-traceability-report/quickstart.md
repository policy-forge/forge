# Quickstart: Traceability Report (WI-38)

## Prerequisites

- Rust 1.93.0+ (Edition 2024)
- Existing FORGE build passes: `cargo test && cargo clippy -- -D warnings && cargo fmt --check`
- An OSCAL artifact generated by `forge convert` with trace metadata (WI-17)

## Implementation Order

### Phase A: Data Structures + Extractor (foundation)

1. **`src/trace/report.rs`** — Define `TraceMetadata`, `TraceEntry`, `TraceSummary`, `TraceReport` structs
2. **`src/trace/extractor.rs`** — Implement `extract_trace_metadata()` and `strip_control_chars()`
3. **`src/trace/mod.rs`** — Module root with re-exports
4. **`src/lib.rs`** — Add `pub mod trace;`
5. **Tests**: Unit tests for extractor (found/not-found/partial metadata, control char stripping)

### Phase B: Walkers (element traversal)

6. **`src/trace/walker.rs`** — Implement `detect_artifact_type()`, `walk_catalog_elements()`, `walk_compdef_elements()`
7. **Tests**: Unit tests with mock JSON for catalog and component-definition walking

### Phase C: Resolver + Formatter (source checks + output)

8. **`src/trace/resolver.rs`** — Implement `check_source_staleness()`, `validate_line_reference()`
9. **`src/trace/formatter.rs`** — Implement `format_trace_table()` with column alignment
10. **Tests**: Unit tests for staleness check, line validation, table formatting (use insta snapshots)

### Phase D: Report Builder + CLI Integration

11. **`src/trace/mod.rs`** — Implement `generate_trace_report()` orchestrator
12. **`src/error.rs`** — Add `TraceUnsupportedArtifact` variant + exit code mapping
13. **`src/cli/trace.rs`** — Implement `execute()` handler
14. **`src/cli/mod.rs`** — Add `Trace` variant to `Commands` enum + dispatch
15. **Tests**: Integration test with fixture OSCAL artifact + source policy

### Phase E: Edge Cases + Polish

16. Error handling tests (missing files, invalid JSON, unsupported type)
17. Coverage gap tests (all unmapped, partial, 100% coverage)
18. Source staleness warning integration
19. `--output` file write test
20. Final quality gates: `cargo test && cargo clippy -- -D warnings && cargo fmt --check`

### Trace Prop Extraction (reuse WI-17 constants)

```rust
use crate::oscal::trace_embedding::{FORGE_TRACE_NS, PROP_SOURCE_FILE, PROP_SOURCE_LINE, PROP_SOURCE_SECTION};

fn extract_trace_metadata(element: &serde_json::Value) -> Option<TraceMetadata> {
    let props = element.get("props")?.as_array()?;
    let mut file = None;
    let mut section = None;
    let mut line = None;

    for prop in props {
        let ns = prop.get("ns").and_then(|v| v.as_str());
        let name = prop.get("name").and_then(|v| v.as_str());
        let value = prop.get("value").and_then(|v| v.as_str());
        if ns != Some(FORGE_TRACE_NS) { continue; }
        match name {
            Some(n) if n == PROP_SOURCE_FILE => file = value.map(String::from),
            Some(n) if n == PROP_SOURCE_SECTION => section = value.map(String::from),
            Some(n) if n == PROP_SOURCE_LINE => line = value.and_then(|v| v.parse().ok()),
            _ => {}
        }
    }

    // At minimum, need section to count as mapped
    let source_section = section?;
    Some(TraceMetadata {
        source_file: file.unwrap_or_default(),
        source_section,
        source_line: line.unwrap_or(0),
    })
}
```
