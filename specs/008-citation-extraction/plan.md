# Implementation Plan: Citation and Reference Extraction

**Branch**: `008-citation-extraction` | **Date**: 2026-02-12 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/008-citation-extraction/spec.md`

## Summary

Implement citation extraction as a pipeline enrichment step (WI-8) that detects inline URLs, bibliographic references (NIST SP, ISO, RFC, FIPS), and internal cross-references (Section, Appendix, Table) in PolicyRequirement text, extracts them into Citation objects linked to their source requirements, strips citation text from the prose, and normalizes whitespace. Uses `regex` crate for pattern detection and `url` crate (already a dependency) for URL validation at the OSCAL layer.

## Implementation Phases

### Phase 1: Domain Model Extension

**Goal**: Add `citations` field to `PolicyRequirement` and `PartialEq` to `Citation`.

1. Add `PartialEq` derive to `Citation` struct
2. Add `citations: Vec<Citation>` field to `PolicyRequirement`
3. Update ALL existing test helpers and constructors across the codebase to include `citations: vec![]`
4. Verify `cargo test --workspace` passes (no regressions)
5. Verify `cargo clippy --workspace -- -D warnings` passes

**Files touched**: `src/model/mod.rs`, `src/parse/atomize.rs`, `src/parse/clauses.rs`, `src/uuid.rs`, `src/model/assemble.rs`, `src/oscal/catalog.rs`, `src/oscal/parts.rs`, `benches/*.rs`

### Phase 2: Citation Extraction Core

**Goal**: Implement `extract_citations_from_text` with URL, bibliographic, and cross-reference detection.

1. Create `src/citation.rs` module
2. Define `LazyLock<Regex>` static patterns (URL, scheme-less URL, bibliographic, cross-reference)
3. Implement `generate_citation_id(requirement_id, citation_text) -> String`
4. Implement match collection with byte range tracking (overlap detection)
5. Implement `extract_citations_from_text(requirement_id, text) -> Result<(String, Vec<Citation>), ForgeError>`
6. Implement prose stripping and whitespace normalization
7. TDD: Write tests for each pattern type, edge cases (EC-1 through EC-7), malformed URLs

**Regex patterns**:
- URL: `https?://[^\s\)\]>,;]+`
- Scheme-less: `\bwww\.[^\s\)\]>,;]+`
- Bibliographic: `\b(?:NIST\s+SP|ISO|RFC|FIPS)\s+\d+[-\w.]*(?:\s+Rev\.?\s*\d+)?(?:,?\s+Section\s+[\w.-]+)?`
- Cross-reference: `\b(?:Section|Appendix|Table)\s+[\dA-Z]+(?:\.\d+)*\b`

### Phase 3: Document-Level Enrichment

**Goal**: Implement `extract_citations` that walks the full document tree.

1. Implement `extract_citations(document: &mut PolicyDocument) -> Result<(), ForgeError>`
2. Recursive section walking (consistent with `assign_stable_ids_to_section` pattern in uuid.rs)
3. Tracing instrumentation: DEBUG log citation counts per requirement
4. TDD: Document-level tests (multiple sections, nested sections, empty document)

### Phase 4: Pipeline Integration

**Goal**: Wire citation extraction into the conversion pipeline.

1. Add `pub mod citation;` to `src/lib.rs`
2. Add re-exports: `pub use citation::extract_citations;`
3. Integrate into `src/cli/convert.rs` pipeline (after UUID assignment, before OSCAL generation)
4. Integration test: end-to-end from PolicyDocument to citations extracted

### Phase 5: Idempotency, Performance, and Final Verification
